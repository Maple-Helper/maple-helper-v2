# Maple Helper v2: roadmap

**Spec:** `docs/superpowers/specs/2026-10-12-maple-helper-v2-design.md` (approved 2026-10-12)
**Parity checklists:** `docs/parity/01-brain-data.md`, `02-vision-platform.md`, `03-shell-ux.md`, `04-play-tools.md`

The spec is too large for one plan, so each milestone gets its own detailed plan. A plan is written **when the previous milestone lands**, so it builds on the real crate names, types and oracle formats rather than guesses. This file is the index and the dependency map.

## Rules for every milestone plan

1. **Oracles first.** The first task of a milestone adds that milestone's oracle sets to `tests/oracle/gen_oracles.py`, generated from the pinned v1 checkout, and commits the JSON. Implementation tasks then make Rust and TS match those oracles.
2. **Parity ticks.** The last task of a milestone walks its parity sections, marks each item `[x]` with the test that covers it, or records a decision. A milestone is done only when its parity sections have no unmarked items.
3. Exit criteria are copied from spec §13 into the plan header, verbatim.
4. CI stays green on `main` after every task.
